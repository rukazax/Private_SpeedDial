# История изменений

## 6.12.1

- Вторая строка папок закреплена при прокрутке: подпапки открытой папки больше не уезжают вместе с плитками, а остаются под первой строкой. Смещение считается по фактической высоте верхней строки; для нижнего расположения панели — аналогично снизу.
- Исправлено: меню папок могло исчезнуть после перезагрузки. Настройка «показывать папки» по умолчанию теперь включена, а значение сохраняется в `chrome.storage.sync` (раньше флаг жил только в памяти страницы).

## 6.12.0

- Функционал тегов удалён полностью: нет редактора в диалоге плитки, нет чипов на карточке, нет поиска по тегам и фильтра по клику. Поле `tags` в данных остаётся пустым массивом ради совместимости схемы; остатки тегов вычищаются санитайзером при старте.
- Поиск: по заголовку, адресу, имени папки и типу ресурса; операторы `папка:…`, `тип:…`, `сайт:…`.
- Фон плитки — снимок сайта, на который она указывает. Доступно: правым кликом по плитке («Фон — снимок сайта»), кнопками в диалоге плитки (600×400, 1200×800, «Обновить»), в режиме выделения и из панели для папки или всех плиток. Размер по умолчанию выбирается в панели; «Обновить» перезапрашивает кадр.
- Снимок отдаёт внешний сервис mShots: адрес страницы уходит на `s0.wp.com`, поэтому включение всегда осознанное — поштучно или с подтверждением для папки.
- Кнопка «Снять фоны-снимки» убирает такие фоны разом.

## 6.11.0

- Полоса папок разделена на два уровня: сверху только папки верхнего уровня, подпапки открытой папки показываются отдельной зависимой строкой под списком. При открытии подпапки вторая строка показывает соседей по родителю, на «Все» — скрыта.
- Теги: редактор в диалоге плитки, чипы на карточке, клик по чипу включает фильтр. Исправлено: сохранение плитки затирало теги пустым массивом.
- Поиск: по тегам, имени папки и типу ресурса; операторы `#тег`, `папка:…`, `тип:…`, `сайт:…`.
- Массовые операции: режим выделения, перемещение, удаление, цвет и теги для группы плиток.
- «Уборка»: дубли по нормализованному адресу (без www, слэша и меток UTM), мусорные заголовки, пустые папки, повреждённые имена.
- Резервная копия: полный снимок в JSON и восстановление с выбором «слить» или «заменить».
- Целостность данных: санитайзер при старте — повреждённые имена, дубли id папок, потерянные родители, осиротевшие плитки, циклы в дереве.
- Приватность: источник иконок по умолчанию — сам сайт (`/favicon.ico`); в панели есть перевод существующих плиток на локальные иконки или на Google.
- Фон-снимок сайта: превью страницы как фон плитки (внешний сервис mShots), поштучно из диалога или пачкой из панели, с явным предупреждением.
- Новые строки интерфейса пока на русском; перевод на 13 языков — в следующем выпуске.

## 6.10.3

- Из браузерного расширения удалены проверки обновлений GitHub и соответствующий фоновый модуль.
- При первом открытии один раз появляется окно «Скачать мобильное приложение» со ссылкой на страницу последнего релиза GitHub с APK. Закрытие окна запоминается; повторные вкладки и перезапуски не вызывают его снова.
- Текст окна и описание способа обновления переведены на 13 языков.
- В Android сохранена недельная проверка обновлений. Сопутствующая APK имеет версию 6.10.3 и прежнюю подпись.

## 6.10.2

- Ссылки на установку расширения в меню и настройках Android ведут на [Private SpeedDial в Chrome Web Store](https://chromewebstore.google.com/detail/private-speeddial/eakakaeklcgnlanmpbndhjdljppehdof).
- Добавлена ссылка магазина в раздел «О приложении и обновления» обеих версий. Команда установки переведена на 13 языков.
- Магазин указан как основной способ установки в README, инструкции и описании GitHub. ZIP для ручной установки сохранён.
- APK и исходники обновлены; публикация в Chrome Web Store выполняется отдельно от релиза GitHub.

## 6.10.1

- В расширении «Скачать мобильное приложение» открывает страницу последнего релиза GitHub с APK.
- В меню Android добавлена явная команда «Скачать расширение для браузера», ведущая на ту же страницу с ZIP расширения; подпись переведена на все 13 языков.
- Версии APK и расширения повышены; опубликованы новые сборки с прежней подписью Android.

## 6.10.0

- Единый публичный репозиторий и релизы GitHub для расширения и Android.
- Удалены ссылки проекта на прежний домен; ссылки в настройках, меню, политике и встроенной плитке ведут на GitHub. Старая неизменённая встроенная плитка мигрирует; пользовательские закладки сохраняются.
- В настройках обеих версий добавлен раздел проекта, загрузок и кнопка «Поделиться приложением». Android использует системное меню отправки; браузер — Web Share или копирование ссылки.
- Общая проверка стабильного GitHub-релиза при открытии: максимум одна попытка за 7 дней, включая ошибки; безопасная проверка версии/URL/файла, предложение обновиться и постоянный пропуск конкретного релиза.
- Все новые строки переведены на 13 языков.
- Выбор второго сервиса синхронизации исключён из облачных настроек, как и выбор основного сервиса.
- Исходники сборки, инструкции, схемы, тестовые скриншоты и проверяемые архивы релиза.

## 6.9.9-android.5 и ранее

Мобильный интерфейс с меню ☰, локальным поиском и заметками, горизонтальными папками и адаптацией к широким экранам. Настройки раскрывающимися разделами, закреплённый заголовок меню, сохранение заметки крестиком с обработкой ошибки записи. Исправления надёжности хранения, импорта, удаления, профилей и синхронизации. Из Android удалены настольная верхняя панель, валюты, интернет-поиск, мастер-пароль, автоблокировка и «Не беспокоить». Предыдущая браузерная база — 6.9.9.
