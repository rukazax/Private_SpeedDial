Настройки Private SpeedDial

Настройки синхронизации

Создайте пустой файл private-speeddial.json в Box и укажите его ID. Box не создаёт файл автоматически.
⚠️ Лимит 4 МБ на файл. При превышении — фоны не будут синхронизироваться.
Получите на oauth.yandex.ru. Права: cloud_api:disk.app_folder или read+write.
Для Mail.ru может потребоваться пароль для внешних приложений.
⚠️ Ключ шифрования не задан. Данные синхронизируются с облаком в открытом виде (JSON). Для сквозного шифрования заполните поле «Ключ шифрования синхронизации» ниже.
Используйте тот же ключ на всех устройствах. При смене — данные придётся загрузить заново.
«Объединить» — рекомендовано для синхронизации между несколькими компьютерами. Данные всех устройств будут слиты, включая корректное удаление элементов.
Данные синхронизируются сразу с двумя серверами. Логин и пароль второго сервиса заполните в его секции выше, переключив основной сервис. Ключ шифрования общий.
Синхронизация запускается автоматически при любом изменении закладок, папок, заметок и настроек.
