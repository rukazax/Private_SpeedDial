Privacy Policy — Private SpeedDial

Last updated: October 12, 2026

Overview

Private SpeedDial is a browser extension that provides a private start page with visual bookmarks (tiles), folders, and notes. The extension is designed around a single principle: your data belongs to you.

Data Collection

The extension does not collect, transmit, sell, or share any personal data with the developer or any third party.

Specifically, the extension does NOT: - collect analytics or telemetry of any kind; - track your browsing activity; - use cookies for tracking; - contain advertising or advertising identifiers; - transfer your bookmarks, notes, settings, or any other data to the developer's servers (the developer operates no servers).

Data Storage

All data (bookmarks, folders, notes, settings) is stored locally on your device using the browser's built-in storage mechanisms (chrome.storage.local, chrome.storage.sync, IndexedDB, Cache API).

  • If browser sign-in with synchronization is enabled, the browser vendor (e.g., Google) may sync extension settings (chrome.storage.sync) between your devices under your browser account — this is governed by the browser vendor's privacy policy, not by this extension.
  • Local data is removed when the extension is uninstalled.

Optional Synchronization

At your explicit choice, the extension can synchronize your data with a server that you configure yourself (WebDAV / Nextcloud / Synology or a compatible cloud service: Dropbox, Box, OneDrive, pCloud, Yandex Disk, Mail.ru Cloud).

  • Synchronization is disabled by default and works only after you enter your own server credentials.
  • Data is sent exclusively to the server address you specify.
  • You can enable end-to-end encryption (AES-GCM with a PBKDF2-derived key): in this case the sync server stores only encrypted data that cannot be read without your key.
  • Your relationship with the chosen storage provider is governed by that provider's privacy policy.

Network Requests

The extension makes network requests only in the following cases: - Favicons: when adding a bookmark, the extension fetches the site's icon. You can choose the private mode, in which icons are fetched directly from the bookmarked site, or the Google favicon service (google.com/s2/favicons), which receives the bookmark's domain name. - Currency widget (optional, disabled by default): fetches public exchange rates. - Synchronization: requests only to the server you configured.

No other network requests are made. The extension contains no remote code: all JavaScript is bundled in the extension package (script-src 'self').

Permissions

All requested permissions are used solely for the features described above: local storage, optional sync scheduling, bookmark import/export on your explicit action, history search on your explicit action, context menu item, and optional notifications.

Any changes to this policy will be published at this URL with an updated date.

Политика конфиденциальности — Private SpeedDial

Дата обновления: 12 октября 2026 г.

Общие положения

Private SpeedDial — расширение браузера, предоставляющее приватную стартовую страницу с визуальными закладками, папками и заметками. Главный принцип: ваши данные принадлежат вам.

Сбор данных

Расширение не собирает, не передаёт и не продаёт никакие персональные данные разработчику или третьим лицам.

В частности, расширение НЕ: - собирает аналитику и телеметрию; - отслеживает действия в браузере; - использует cookies для отслеживания; - содержит рекламу; - передаёт закладки, заметки или настройки на серверы разработчика (серверов у разработчика нет).

Хранение данных

Все данные (закладки, папки, заметки, настройки) хранятся локально на вашем устройстве средствами браузера (chrome.storage.local, chrome.storage.sync, IndexedDB, Cache API).

  • Если включён вход в браузерный аккаунт с синхронизацией, настройки расширения могут синхронизироваться между вашими устройствами средствами браузера — это регулируется политикой конфиденциальности производителя браузера.
  • Локальные данные удаляются при удалении расширения.

Опциональная синхронизация

По вашему выбору расширение может синхронизировать данные с сервером, который вы настраиваете сами (WebDAV / Nextcloud / Synology или совместимый облачный сервис: Dropbox, Box, OneDrive, pCloud, Яндекс Диск, Облако Mail.ru).

  • Синхронизация выключена по умолчанию и работает только после ввода ваших учётных данных.
  • Данные отправляются исключительно на указанный вами адрес сервера.
  • Доступно сквозное шифрование (AES-GCM с ключом, производным от PBKDF2): сервер хранит только зашифрованные данные, которые невозможно прочитать без вашего ключа.
  • Ваши отношения с выбранным провайдером хранилища регулируются политикой конфиденциальности этого провайдера.

Сетевые запросы

Расширение выполняет сетевые запросы только в следующих случаях: - Favicon: при добавлении закладки загружается иконка сайта. Можно выбрать приватный режим (иконка загружается напрямую с сайта) или сервис Google favicon (ему передаётся домен закладки). - Виджет курсов валют (опционально, выключен по умолчанию): загрузка публичных курсов валют. - Синхронизация: запросы только к настроенному вами серверу.

Других сетевых запросов нет. Удалённый код не используется: весь JavaScript находится в пакете расширения (script-src 'self').

Разрешения

Все запрашиваемые разрешения используются исключительно для описанных выше функций: локальное хранение, планирование синхронизации, импорт/экспорт закладок по вашей явной команде, поиск по истории по вашей явной команде, пункт контекстного меню и опциональные уведомления.

Изменения политики

Любые изменения публикуются по этому же URL с обновлением даты.

Контакты

Вопросы по политике конфиденциальности — через сайт разработчика: GitHub

При открытии приложение проверяет последний стабильный релиз через публичный GitHub API не чаще раза в 7 дней. GitHub получает IP-адрес и обычные сетевые метаданные. Закладки, заметки, пароли и токены в этот запрос не передаются. Выбор «Пропустить релиз» хранится только на этом устройстве. / On launch, the app checks the public GitHub releases API at most once every 7 days. GitHub receives the IP address and standard request metadata, never your bookmarks, notes, passwords or tokens. Skipped releases are stored on this device only.
