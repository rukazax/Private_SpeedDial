При открытии приложение проверяет последний стабильный релиз через публичный GitHub API не чаще раза в 7 дней. GitHub получает IP-адрес и обычные сетевые метаданные. Закладки, заметки, пароли и токены в этот запрос не передаются. Выбор «Пропустить релиз» хранится только на этом устройстве. / On launch, the app checks the public GitHub releases API at most once every 7 days. GitHub receives the IP address and standard request metadata, never your bookmarks, notes, passwords or tokens. Skipped releases are stored on this device only.
