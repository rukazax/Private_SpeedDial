# Проверка Android.3

Финальный APK: `Private-SpeedDial-6.9.9-android.3.apk`, 1,538,963 байт.
SHA-256: `c3b4eb8b95860ec9a0d36e6aac9c75cc0987c54627bd6945c66934b2858cfac0`.

125 функциональных проверок прошли на финальном APK. Дополнительно прошли 12 проверок Android Instrumentation, включая сохранение заметки и записи SQLite размером более 2 МБ после завершения процесса, приватный origin, связь с фоновым контекстом, криптографию, FLAG_SECURE и отсутствие debuggable. Свайпы папок в обе стороны и долгое нажатие проверены через сенсорные события.

| Группа | Проверок |
|---|---:|
| home | 31 |
| extended-home | 7 |
| settings | 24 |
| extra | 11 |
| sync | 39 |
| advanced-sync | 13 |

Проверены создание/правка/удаление закладок, папок и заметок, вложенные и защищённые папки, поиск, сортировка, профили, темы, фон, JSON/HTML/CSV/FVD, прокрутка 110 закладок, размеры 320/360/412/600/800/960 px. На широком экране плитки сохраняют ширину, число столбцов увеличивается, если следующий столбец помещается.

Системные SAF-диалоги отдельно подтвердили экспорт JSON/HTML, импорт JSON без изменения массивов данных, отмену выбора файла, работу Android Back в настройках и Android Share. Эти проверки выполнены перед последними изменениями только логики выбора папки; файловый мост и Activity после них не менялись.

Синхронизация: локальный HTTP WebDAV GET/PUT/PROPFIND; plaintext и AES-GCM; неверный/отсутствующий ключ не перезаписывает сервер; merge/upload/download; три стратегии конфликтов; удаления; два сервера и частичный отказ; HTTP401/429 и неправильный JSON; native multipart для Box/pCloud; тестовые ответы всех 8 провайдеров; реальные 30 секунд дебаунса автосинхронизации; обработчик таймера; UTF-8 лимиты; отмена запроса и удаление реквизитов при перенаправлении на другой порт.

Реальные облачные учётные записи и физический складной телефон не проверены. Выполнение подтверждено на Android15/WebView124, не на всех поддерживаемых версиях Android. Расписание работает при открытом приложении. Изображения v3-home/v3-wide/v3-settings получены в проверочной сборке; финальная сборка закрывает снимки экрана. Эмулятор userdebug может самостоятельно включать DevTools; в исходниках DEBUG_WEBVIEW=false.

Использовались только тестовые данные. Оригинальный ZIP расширения не изменён. Подпись сохранена для обновления предыдущей версии. Удалены тестовые записи из базы эмулятора; ключ подписи и его пароль в архив не включены.
