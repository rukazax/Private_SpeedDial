# Private SpeedDial Android.5 — изменения и проверка

APK: `Private-SpeedDial-6.9.9-android.5.apk`. SHA-256: `211e90d3567abfff41ac32a3b5f3d328c644c7c52c7b4be27ce5fa71b74ec6e2`.

Заголовок выпадающего меню закреплён при прокрутке. Добавлен последний пункт «Расширение для браузера»; такая же ссылка расположена рядом с обоими пунктами поддержки проекта. По указанию пользователя все три ссылки ведут на https://chromewebstore.google.com/.

В разделе заметок кнопка подписана «+ Заметка». Крестик справа сверху сохраняет заметку и закрывает форму через единый обработчик сохранения. Если заголовок не введён, используется первая строка текста. Пустая новая форма закрывается без создания пустой записи. Исправлено скрытие ошибки записи в заметках: при сбое форма остаётся открытой, введённый текст сохраняется, изменения в памяти откатываются; повторное сохранение не создаёт дубликат. Крестик остаётся доступен при прокрутке формы.

Переведены Android-меню, подписи и подсказки доступности, команды перемещения, системные сообщения Java, поля облачных провайдеров и страница конфиденциальности. Полные словари содержат 384 ключа для каждого из 13 языков: en, ru, de, es, fr, it, pt, zh, ja, ko, tr, hi, ar. Пропущенных ключей и несовпадающих параметров подстановки не обнаружено. В интерфейсе проверены главный экран, меню и настройки на всех языках, включая направление RTL для арабского. Системные сообщения Java отдельно сопоставлены со словарём каждого языка.

На финальном подписанном APK прошли 188 функциональных проверок и 14 проверок Android Instrumentation после повторного запуска.

Проверки охватывают закладки, вложенные и защищённые папки, заметки, поиск, сортировку, профили, темы, фоны, импорт JSON/HTML/CSV/FVD, экспорт HTML, прокрутку 110 закладок и ширины 320–960 px. Синхронизация проверена через локальный WebDAV и тестовые ответы восьми провайдеров: merge/upload/download, конфликты, удаления, два сервера, ошибки, AES-GCM, неверные ключи, ограничения UTF-8 и автоматическая отправка через 30 секунд.

Новые сенсорные проверки подтверждают закрепление заголовка меню, последний пункт ссылки, подпись «+ Заметка», сохранение новой/изменённой заметки крестиком, работу без заголовка, пустую форму, прокрутку и восстановление после тестовой ошибки записи. Android Instrumentation проверяет сохранение заметки и большой записи SQLite после завершения процесса, криптографию, FLAG_SECURE, отсутствие debuggable, исходящие ACTION_VIEW всех трёх ссылок и системные сообщения на 13 языках.

Проверки выполнены в эмуляторе Android15/WebView124. Физический Honor Magic V3 не подключён; реальные облачные аккаунты не использовались. Ссылки на магазин проверены по сформированным Android Intent, без установки расширения в браузер эмулятора. Расписание работает при открытом приложении. Изображения v5-menu/v5-note/v5-settings получены в проверочной сборке; финальная сборка использует FLAG_SECURE. Служебные заметки и большая тестовая запись удалены из базы. APK устанавливается поверх предыдущей версии с тем же ключом подписи.
