# Установка и использование

## Android

Системные требования: Android 8.0+ (API 26), актуальный Android System WebView. Разрешение приложения — доступ к сети. Для импорта и экспорта используются системные диалоги; постоянный доступ ко всем файлам не нужен.

[Скачать последнюю APK](https://github.com/rukazax/Private_SpeedDial/releases/latest/download/Private-SpeedDial-Android.apk). Проверить контрольную сумму можно по `SHA256SUMS.txt` в том же релизе. После установки разрешение на установку неизвестных приложений у браузера можно отключить.

При обновлении сохраните резервную копию JSON, затем откройте новый официальный APK поверх установленной версии. Пакет `su.econa.speeddial` и подпись сохранены для совместимости. Это технический идентификатор прежнего приложения, а не ссылка на сайт. При ошибке несовместимой подписи сначала убедитесь, что установлена официальная версия; не удаляйте её до экспорта данных.

## Расширение

Основной способ: [установить Private SpeedDial из Chrome Web Store](https://chromewebstore.google.com/detail/private-speeddial/eakakaeklcgnlanmpbndhjdljppehdof). На странице нажмите «Установить» / «Добавить в Chrome» и подтвердите разрешения. Затем закрепите значок и откройте панель из меню расширения. Магазинную версию обновляет браузер.

Для ручной установки и разработки доступен [ZIP из GitHub Releases](https://github.com/rukazax/Private_SpeedDial/releases/latest/download/Private-SpeedDial-Extension.zip): распакуйте его, откройте `chrome://extensions`, включите режим разработчика и нажмите «Загрузить распакованное расширение». Выберите папку с манифестом и не перемещайте её после установки.

Для обновления распакованной версии экспортируйте JSON, замените файлы в той же папке новой версией и нажмите «Обновить» в `chrome://extensions`. Не удаляйте расширение без резервной копии: может измениться идентификатор и область хранения. Версия исходников этого выпуска — `6.10.3`. Версия в магазине может отличаться; выпуск в GitHub не означает автоматической публикации в Chrome Web Store. Не смешивайте способы установки без резервной копии данных.

Клавиши Chrome: открыть панель — `Ctrl+Shift+Y`, синхронизация — `Ctrl+Shift+S`, поиск — `Ctrl+Shift+F`; на macOS используется Command. Если сочетание занято, измените его в `chrome://extensions/shortcuts`.

## Закладки и папки

На Android откройте ☰ → «Добавить закладку», укажите URL и заголовок, выберите папку, цвет или иконку и сохраните. Ссылка открывается во внешнем браузере. Из другого Android-приложения можно отправить ссылку через системную команду «Поделиться» в Private SpeedDial — откроется форма добавления.

Долгое нажатие на плитку открывает команды редактирования, перемещения и удаления. Для изменения папки используйте её контекстное меню. Поддерживаются вложенные папки и пароль отдельной папки. Пароли папок ограничивают интерфейсный доступ; локальная база остаётся доступной разблокированному устройству/системе.

Папки Android прокручиваются пальцем влево и вправо в строке справа от ☰. На складном устройстве приложение запоминает минимальную ширину основного экрана. Если первый запуск выполнен сразу на большом экране, до открытия внешнего экрана используется ориентир 360 dp. После раскрытия добавляются столбцы, а ширина плиток сохраняется. Поведение конкретного Honor Magic V3 требует проверки на физическом телефоне.

## Заметки и поиск

Android: ☰ → «Заметки» → «+ Заметка». Введите текст и необязательный заголовок. Крестик справа сверху **сохраняет и закрывает**, как кнопка «Сохранить». Если заголовок не указан, он берётся из первой строки текста. Пустая новая заметка не создаётся. Если запись не удалась, форма остаётся открытой для повторной попытки.

Поиск в начале меню ищет по локальным закладкам и заметкам. Интернет-поиска в Android нет. В настольной версии заметки и поиск расположены в её исходном интерфейсе.

## Настройки, профили и оформление

В Android ☰ → «Настройки»: разделы раскрываются по нажатию на заголовок. Можно выбрать язык, тему, фон, параметры закладок, профиль, импорт/экспорт и синхронизацию. Профили разделяют наборы данных; перед переносом убедитесь, что выбран нужный профиль. В настольной версии сохранены настройки её собственного интерфейса.

В разделе **«О приложении и обновления»** находятся репозиторий, загрузки и **«Поделиться приложением»**. Android открывает системный выбор приложения для отправки ссылки. В браузере используется системная функция Web Share, а при её отсутствии ссылка копируется. Если копирование запрещено, доступно поле с URL для ручного копирования.

## Перенос и резервные копии

1. В исходной версии откройте настройки и экспортируйте JSON.
2. Сохраните резервную копию отдельно. JSON может содержать личные данные; не размещайте его в Issues или публичном репозитории.
3. В новой версии выберите импорт и этот файл. Проверьте закладки, заметки и папки.
4. При желании настройте общее облако по [инструкции](SYNC.md). Не загружайте пустой профиль поверх заполненного облачного файла; сначала выберите объединение или скачивание.

Также поддерживается импорт HTML, CSV и FVD; экспорт HTML удобен для переноса ссылок в обычный браузер. Для полного переноса данных предпочтителен JSON. Для каждого важного профиля делайте отдельный экспорт.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| ☰ не открывается | Установлена ли последняя APK; перезапустите приложение, обновите System WebView. При обращении укажите модель/Android и наличие затемнения |
| Синхронизация не проходит | URL и права провайдера, токен/пароль, сеть, одинаковый ключ шифрования; используйте «Проверить соединение» |
| Обновление не предлагается | Оно должно быть стабильным и новее установленной версии, иметь нужный файл и не быть пропущено; после попытки действует интервал 7 дней, в том числе при ошибке |
| Разные наборы закладок | Проверьте активный профиль, выбранную папку, режим и адрес синхронизации |
| Импорт не проходит | Формат и структура файла; ограничения размера FVD указаны в интерфейсе. Сохраните исходный файл |
| APK не обновляет установленную | Сравните источник и подпись; сохраните экспорт перед любыми действиями с удалением |

[Создать обращение](https://github.com/rukazax/Private_SpeedDial/issues). Не публикуйте секреты и личные данные.

## Загрузка другого клиента

В браузерных настройках ссылка «Скачать мобильное приложение» открывает страницу последнего релиза GitHub. В Android ☰ → «Установить расширение для браузера» открывает [Chrome Web Store](https://chromewebstore.google.com/detail/private-speeddial/eakakaeklcgnlanmpbndhjdljppehdof). Эта же ссылка есть вверху и внизу настроек, а также в разделе «О приложении и обновления». Для телефона на странице релиза выберите `Private-SpeedDial-Android.apk`; ZIP расширения сохранён как вариант ручной установки.

При первом открытии расширения один раз появляется окно «Скачать мобильное приложение» со ссылкой на [страницу релизов с APK](https://github.com/rukazax/Private_SpeedDial/releases/latest). Закрытое окно не повторяется после перезапуска или обновления. Проверка обновлений GitHub в расширении отсутствует; недельная проверка сохранена только в Android.
