## Что означает проверка релизов

Будущие `v6.11.0` и `v6.12.0` в тестах — **имитированные метаданные**, они не публикуются в GitHub. Проверяется настоящий клиентский код и UI: первая проверка, кеш, пропуск, повторное открытие и загрузка нужного файла. Нативная Instrumentation перехватывает исходящий ACTION_VIEW и ACTION_CHOOSER до передачи внешнему приложению; она проверяет адрес загрузки и содержимое отправки, не отправляя сообщение третьим лицам.

Публичную доступность репозитория, GitHub latest и загруженных файлов следует проверять отдельно после публикации. Сценарий `tools/publish-release.py` создаёт черновик, сверяет скачанные из него файлы с локальными, публикует и затем повторно проверяет публичный API и SHA-256 всех загрузок. Локальные тесты сами по себе не подтверждают публикацию.

## Границы

- Физический Honor Magic V3 не подключён и не проверен. Широкие окна эмулируются; они не воспроизводят все особенности прошивки складного телефона.
- WebDAV и другие облачные API проверяются локальным тестовым сервером и имитацией ответов. Реальные аккаунты всех провайдеров не использовались.
- Проверка криптографии — тесты работы и ошибок существующего кода, не независимый криптографический аудит.
- Автосинхронизация Android проверена при открытом приложении; после закрытия Activity фоновой службы нет.
- Интерфейсы проверяются debug-webview сборкой для CDP и скриншотов. Доставляемая APK отдельно собрана без отладки и проверена Instrumentation; её контрольная сумма записана в сводном отчёте и релизе.

## Воспроизведение

Команды и зависимости: [BUILD.md](BUILD.md). Основные новые тесты: `tests/updates.test.cjs`, `tests/sync-privacy.test.cjs`, `tests/browser.test.cjs`, `verification/project-v6.mjs`, `verification/ReleaseInstrumentationV6.java`.

Для проверки итоговой APK установите её и тестовый APK после команды `SPEEDDIAL_TEST_TAG=v6 python3 verification/build-instrumentation.py`, затем запустите `python3 verification/native-release-v6.py`. Тестовая Instrumentation подписывается тем же локальным ключом и не включается в пользовательский релиз.
