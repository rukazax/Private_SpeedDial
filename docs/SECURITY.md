# Приватность и безопасность

## Хранение

В расширении данные хранятся в IndexedDB и Chrome storage; в Android — приватной SQLite и SharedPreferences. Дополнительного шифрования всей локальной базы в мобильной версии нет. Разблокированное/скомпрометированное устройство, root и отладочные инструменты находятся вне защиты интерфейсных паролей папок. В Android нет мастер-пароля и автоблокировки; используйте блокировку самого устройства.

Официальная Android release-сборка запрещает отладку WebView и использует FLAG_SECURE для ограничения снимков/записи экрана. Android Auto Backup отключён. FLAG_SECURE не заменяет шифрование данных и не гарантирует защиту на модифицированных прошивках.

## Сеть

- Синхронизация обращается к выбранным пользователем сервисам. Ключ шифрования при задании защищает облачный payload AES-GCM/PBKDF2; без него payload — JSON.
- HTTPS проверяет сертификаты. HTTP оставлен для совместимости с локальным WebDAV и не защищает трафик.
- Иконки сайтов и фоны по URL могут загружаться со сторонних адресов. Выбирайте локальные изображения/подходящий источник иконок, если это существенно для вашей модели приватности.
- Настольные валюты и интернет-поиск сохранены в расширении; в Android удалены.
- Только Android-проверка обновлений обращается к публичному GitHub API максимум раз в 7 дней при открытии интерфейса. GitHub видит IP и обычные сетевые метаданные. Закладки, заметки, реквизиты, профиль и ключи в этот запрос не передаются.
- Кнопка «Поделиться» передаёт только название и публичную ссылку проекта. Пользователь сам выбирает адресата и подтверждает отправку в выбранном приложении.

## Разрешения и внешние страницы

Android имеет только INTERNET. Системные диалоги используются для импорта и экспорта. Нативный мост доступен только встроенным доверенным страницам APK под appassets origin; внешние http(s)-ссылки открываются в другом приложении. Android проверяет допустимые схемы URL, а HTTP-клиент не переносит Authorization/Cookie при переходе на другой origin и запрещает HTTPS→HTTP перенаправление.

У расширения широкие host_permissions HTTP/HTTPS для произвольных WebDAV-серверов и внешних ресурсов; storage/unlimitedStorage для базы и фонов, tabs/windows/contextMenus для открытия панели/добавления сайтов, bookmarks/history для соответствующих пользовательских функций, alarms для расписаний, notifications — необязательное разрешение. Полный список находится в manifest.json. Удалённые скрипты не загружаются: CSP разрешает скрипты только из расширения.

## Релизы и секреты

Официальные APK подписываются постоянным ключом. Проверяйте источник, подпись и SHA256SUMS. Ключ подписи, пароль, личные экспорты и облачные реквизиты не включены в репозиторий. Сборка из исходников на другом компьютере создаёт собственную подпись и не может заменить официальный APK без совпадения ключа.

Android-приложение предлагает скачивание обновления, не устанавливает его самостоятельно. Адреса релиза и нужного файла сверяются с закреплённым репозиторием GitHub. Как и любой выпуск через GitHub, доверие к обновлению зависит также от безопасности аккаунта владельца и ключа подписи.

## Сообщить об уязвимости

Не размещайте рабочие токены, пароли, ключи или личные данные в публичных Issues. Для обычного дефекта создайте [Issue](https://github.com/rukazax/Private_SpeedDial/issues) с обезличенными шагами. Для чувствительного случая сначала проверьте наличие приватного канала сообщения в разделе Security репозитория; если его нет, создайте обращение с просьбой согласовать приватный канал без раскрытия деталей эксплуатации и секретов.

Независимый аудит безопасности проекта не проводился. Отчёт о тестах описывает выполненные локальные проверки, а не сертификацию.

Официальная страница установки расширения: [Private SpeedDial — Chrome Web Store](https://chromewebstore.google.com/detail/private-speeddial/eakakaeklcgnlanmpbndhjdljppehdof). Для ручной установки доступны исходники и ZIP в GitHub Releases. Версии магазина и GitHub обновляются отдельными процедурами.

Расширение не обращается к GitHub API для проверки релизов. Одноразовое приглашение скачать Android работает локально; страница GitHub открывается только по нажатию кнопки. Флаг показа хранится только в локальном профиле расширения и не включается в облачный файл.
